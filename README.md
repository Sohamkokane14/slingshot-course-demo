# Cyber Security Slingshot Quiz (sample demo)

A small browser game by keenmind designs. Pull back the slingshot and burst a box. Each box asks one cybersecurity question (KBC style, 4 options). Right answers score 10 points, wrong answers reveal the correct one.

Built with HTML5 canvas, Matter.js and canvas-confetti. No build step. Sample demo, not client work.
